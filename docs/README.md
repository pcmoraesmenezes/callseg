# Documentação

| Pasta | O que tem | Leia quando |
|---|---|---|
| [`architecture/`](architecture/README.md) | os quatro diagramas e o estilo de arquitetura | quiser entender como as peças se encaixam |
| [`adr/`](adr/) | uma decisão por arquivo: contexto, decisão, alternativas, consequências | quiser saber **por que** algo é como é |
| [`guides/`](guides/) | desenvolvimento, infraestrutura, CI e CD, operação | for mexer, implantar ou operar |
| [`reports/`](reports/) | model card e pré-mortem | quiser os números, os limites e os riscos |

Os números dos relatórios vêm de `reports/metrics.json` (gerado pelo caderno); não edite os `.md` de `docs/reports/` à mão, rode `make docs`.
